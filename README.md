## 🚀 Engineering Vision

This portfolio is not just a collection of links; it is a **Technical Manifesto**. Built with a "Product-First" mindset, it utilizes a modular **Bento UI** architecture and a strict Design System to bridge the gap between aesthetic prestige and system performance.

### Core Pillars:
- **Web3 Ecosystem:** Specialized in Stellar Soroban (Rust) smart contracts and DeFi risk models.
- **AI Integration:** Implementing hybrid recommendation engines and data pipelines with high validation accuracy.
- **Fullstack Reliability:** Architecting scalable microservices and high-fidelity React interfaces.

---

## 🛠 Technical Stack

### Frontend & UI/UX
- **Framework:** React 19 (Hooks, Concurrent Mode)
- **Styling:** Tailwind CSS v4.0 (Engineered with `@theme` tokens)
- **Animations:** Framer Motion 12 (Gesture-driven interactions)
- **Typography:** Geist (Headlines), Inter (Body), JetBrains Mono (Technical labels)
- **Icons:** Lucide React & Material Symbols

### Architecture & Routing
- **Build Tool:** Vite 8.0 (ESM-first, sub-second HMR)
- **Routing:** React Router 7 (Implementation via `HashRouter` for universal hosting)
- **Icons:** SVG-first icon sets for zero-latency rendering.

## 💎 Featured Engineering Systems

### [UdonFi Protocol](https://udonfi-1404.web.app/)
*1st Prize Winner – Stellar Mini Hackathon*
- **The Challenge:** Bypassing Soroban VM instruction limits and ledger storage costs.
- **The Solution:** Implemented **u128 state bitmap packing** to reduce storage footprint by 95% and engineered a **cryptographically linked 2-step liquidation flow**.

### [VioTune AI](https://github.com/TheAnh1404/VioTune)
- **The System:** A hybrid recommendation engine utilizing SVD Matrix Factorization and KNN models.
- **Efficiency:** Bridging FastAPI inference layers with real-time React consumers for hyper-personalized audio discovery.

### [LaBouffe Platform](https://github.com/TheAnh1404/LaBouffe)
- **Scale:** A high-concurrency food delivery ecosystem focusing on automated order management and real-time tracking pipelines.

## 📐 Design System

The application utilizes a custom design framework defined in `src/index.css`, inspired by **Material Design 3**:
- **Dynamic Colors:** Uses a spectrum of Surface, Primary, Secondary, and Tertiary containers.
- **Bento Grid:** A modular 12-column responsive layout for logical information hierarchy.
- **Glassmorphism:** Strategic use of backdrop filters for high-fidelity navigation and overlays.

## 🛠 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TheAnh1404/TheAnhPortfolio.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch the dev engine:**
   ```bash
   npm run dev
   ```

4. **Production Build:**
   ```bash
   npm run build
   ```
